# PeerEval - Peer Evaluation System

A Django-based web application for managing peer evaluations in educational settings. This system allows instructors to create and manage peer evaluation assignments, while students can submit evaluations for their peers.

## Features

- **User Management**
  - Multiple user roles (Superuser, Department Head, Course Coordinator, Instructor, Student)
  - Secure authentication and session management
  - Role-based access control

- **Course Management**
  - Department and course creation
  - Section management
  - Student enrollment
  - Term-based organization

- **Evaluation System**
  - Create and manage peer evaluation assignments
  - Student submission interface
  - Evaluation tracking and statistics

- **Dashboard**
  - Instructor dashboard with course statistics
  - Student list management
  - Quick actions for common tasks
  - Search and filter capabilities

## Tech Stack

- **Backend**: Django 5.1.7
- **Frontend**: 
  - Tailwind CSS
  - Django Templates
- **Database**: SQLite3 (Development)
- **Authentication**: Django's built-in authentication system
- **Security**: 
  - HTTPS enforcement
  - Secure session management
  - CSRF protection
  - HSTS enabled

## Prerequisites

- Python 3.x
- Node.js and npm (for Tailwind CSS)
- Virtual environment (recommended)
